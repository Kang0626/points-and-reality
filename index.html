FAQ

Common questions

How is 3DGS different from traditional 3D models? +
Unlike polygon meshes that require manual retopology and texture baking, 3D Gaussian Splatting captures radiance directly as millions of light-emitting ellipsoids — achieving photorealistic quality with zero manual work.
Do viewers need to install anything? +
No. Everything renders through standard WebGL 2.0 — works in any modern browser on desktop and mobile with zero plugins or apps.
Can I embed the 3D viewer on my own site? +
Yes — every deliverable includes a standalone URL and responsive iframe code ready for Shopify, WordPress, or any custom site.
